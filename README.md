# PSAG

PSAG: Calibrating Linguistic Rules with Semantics for Low-Resource Short Answer Grading

This repository provides the dataset and source code associated with our research on low-resource short answer grading (SAG).

Repository Contents

The repository contains two ZIP archives:

ESA Data (ESA_data.zip): Contains the ESA dataset used in our experiments. Detailed information about the dataset and its structure is provided in the README included in the archive.

PSAG Code (PSAG_code.zip): Contains the implementation of the proposed PSAG method. Instructions for environment setup, configuration, and execution are provided in the README included in the archive.

Usage

Please download and extract the corresponding ZIP archive. Refer to the README file inside each archive for detailed instructions.

Notes

These resources are provided to support research reproducibility and further studies on short answer grading.
